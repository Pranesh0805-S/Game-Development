# Rift Runner V2

**Rift Runner** is an original Python + Pygame platformer. You play a courier crossing a fractured neon city by shifting between **Reality** and the **Rift**. Each state exposes different routes, dangers, and energy shards.

## Run it

```bash
pip install -r RiftRunnerV2/requirements.txt
python RiftRunnerV2/main.py
```

## Controls

| Action | Key |
| --- | --- |
| Move | A / D or Left / Right |
| Jump | Space, W, or Up |
| Shift worlds | Left Shift |
| Pause | Escape |
| Restart level | R |

The game stores progress and settings in `RiftRunnerV2/data/` when it runs. This folder is intentionally ignored by Git.
